Screen-Time Report — one original funny line about everyday phone life for make.fun's "One-Line Laugh Sprint" bounty ($5 in USDC). `main.ts` (pure Node.js stdlib, no dependencies, fully deterministic) writes a single vivid scene to `entry.txt`: your phone reports 7 hours of screen time a day, and the very act of opening the report to check it pushes the total to 8 — the twist lands on the last word.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```

This writes one line (106 characters, no trailing newline) to `./output/entry.txt`.
